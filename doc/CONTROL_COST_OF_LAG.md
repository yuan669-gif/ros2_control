# 滞后一周期到底值多少：从"周期数"到"相位裕度"

日期：2026-09-21
关联：`doc/FORMAL_MODEL.md`（定理 2：单趟滞后 = 级联深度）、`doc/TWO_PASS_VS_SINGLE_PASS.md`
测试：`hierarchical_control/test/test_stale_state_cost.cpp`（3 个用例，全部通过）

定理 1/2 说明：单趟执行使父节点读到**落后 L 个周期**的子状态，`L` 等于级联深度。
本文回答下一个问题：**这在工程上值多少钱？**

---

## 1. 为什么不能只看追踪误差的 RMS

第一版实验用"正弦参考下的 RMS 追踪误差"作为指标，结果滞后 0→3 周期几乎不变
（比值 0.97–1.00）。原因是量纲没对上：1 kHz 控制下 1–3 个周期只有 1–3 ms，
对 1 Hz 参考和低带宽回路完全可以忽略。

**这是一条方法学教训**：必须选一个**能暴露效应**的指标。对"反馈用了陈旧状态"这类问题，
正确的框架是**纯传输延迟**，正确的指标是**相位裕度**。

---

## 2. 正确框架：滞后 = 传输延迟

反馈路径中 `L` 个周期的滞后等价于纯传输延迟

```text
τ = L · Δt                （Δt = 控制周期）
```

对开环 `L(s) = C(s)·P(s)·e^{-sτ}`，穿越频率 `ω_c` 处的相位裕度损失为

```text
ΔPM = ω_c · τ  =  2π · f_c · L · Δt   [rad]  =  360 · f_c · L · Δt   [deg]
```

注意 `ΔPM` **与 `f_c·Δt` 成正比**——即与"穿越频率占控制频率的比例"成正比。这解释了为什么
危害是相对的。

---

## 3. 每周期代价（Δt = 1 ms，即 1 kHz）

| 穿越频率 f_c | 每周期损失 | L=1 | L=2 | L=3 |
|---|---|---|---|---|
| 10 Hz | 3.6° | 3.6° | 7.2° | 10.8° |
| 50 Hz | 18° | 18° | 36° | 54° |
| 100 Hz | 36° | 36° | 72° | 108° |
| 200 Hz | 72° | 72° | 144° | 216° |

**同样的 1 个周期：低带宽回路损失 3.6°，高带宽回路损失 72°。**

---

## 4. 闭式验证（被测例）

PD 控制双积分器：`C(s) = kp + kd·s`，`P(s) = 1/s²`，穿越频率满足 `ω_c⁴ = kd²ω_c² + kp²`。

取 `kp = 10, kd = 600` → `f_c ≈ 95.5 Hz`，`Δt = 1 ms`：

| L | τ | 相位裕度 |
|---|---|---|
| 0 | 0 ms | **90.0°** |
| 1 | 1 ms | **55.6°** |
| 2 | 2 ms | **21.2°** |
| 3 | 3 ms | **−13.1°（不稳定）** |

对照低带宽：`kp = 10, kd = 60` → `f_c ≈ 9.5 Hz`，同样 `Δt = 1 ms`：

| L | 相位裕度 |
|---|---|
| 0 | 89.8° |
| 3 | **79.5°（几乎无影响）** |

**时间域确认**：`kd = 600` 时 `L = 0` 稳定、`L = 3` 发散；`kd = 60` 时 `L = 3` 仍稳定。
与相位裕度预测一致。

---

## 5. 工程结论：滞后给闭环带宽设了上限

给定相位裕度预算 `B`（例如 30°）：

```text
f_c  ≤  B / (2π · L · Δt)
```

`Δt = 1 ms`、`B = 30°` 时：

| 深度 L | 可用闭环带宽上限 |
|---|---|
| 1 | 83 Hz |
| 2 | **42 Hz** |
| 4 | **21 Hz** |

也就是说：**如果级联深度是 D 且你用的是单趟执行，那么为了保住 30° 裕度，
闭环带宽被迫压到约 `1/(12·D·Δt)` 以下。** 两趟执行把这条限制去掉。

这是一条可以直接写进论文的、可操作的结论：**深度不只是"多跑几层"，它直接决定了
你能做多快的控制。**

---

## 6. 与课题主线的接合

| 结论 | 来源 | 工程含义 |
|---|---|---|
| 单趟必然使一个方向陈旧（定理 1） | 穷举 6 种顺序的测试 | 不是实现缺陷，是结构性 |
| 陈旧量 = 深度 D（定理 2） | 阶跃响应，内核 + 真实管理器 | 深级联代价线性增长 |
| 两趟使两方向都新鲜（定理 3） | 内核 + 管理器测试 | 去掉带宽上限 |
| **滞后 L = 延迟 L·Δt，损失 `ω_c·L·Δt` 相位裕度** | 本文 | **高带宽级联（正是需要同周期传播的那类）会被 1–3 个周期打垮** |

这条链条把"调度顺序"与"控制性能"接起来了，也解释了为什么上游的静默降级不是无害的：
它恰好惩罚那些带宽最高、最需要同周期传播的系统。

---

## 7. 限制（不要越界）

1. **线性、无饱和**：例中是 PD + 双积分器；未含摩擦、量化、饱和、采样抖动。
2. **相位裕度是经典准则，不是稳定性证明**；本文给出的是损失公式与其数值验证。
3. **小延迟近似**：`ω_c τ` 的一阶损失在 `τ` 远小于 `1/ω_c` 时准确；本文例中 `ω_c τ` 最大为
   0.6 rad，仍在合理范围（表格中 `L≥3` 已越界，故同时用时间域确认）。
4. **`Δt` 是控制周期**：多频/异步系统需要按最慢相关回路重算。
5. **6 个周期的深度尚未验证**：表格可外推，但实验只做到 `L = 4`。

---

## 8. 现实被控对象下的稳健性（2026-09-22 **重测并修正**）

> ⚠ **本节曾在 2026-09-21 用错误数值发布，现已重测。**
> 原版报告"摩擦与量化不改变结论（差异 <0.1%）"与"每周期把可用增益除以 (L+1)"，
> 其 `kd_max` 全部来自**显式 Euler 积分**，真实含义是**积分格式的稳定性上限 `Δt·kd = 2`**，
> 不是控制回路的可用增益上限。因为该格式里有效阻尼恰为 `kd`，这个假上限**天然按 `1/(L+1)`
> 随深度缩放**，所以看起来"与理论吻合"。
> 完整诊断见 `doc/SCHEDULING_PERFORMANCE_COST.md`。

### 8.0 修正后的数值方法

被控对象 `m=1`、`kp=100`、`Δt_int = 1e-5`、1 Hz 正弦参考、幅值 1；
位置与速度**都延迟** `L` 个控制周期（1 个周期 = 1 ms = 100 个积分步）。
积分用 `x''=u` 在步内控制量常值下的**精确更新**
（`x ← x + Δt·v + Δt²/2·u`，`v ← v + Δt·u`），该格式**不对 `kd` 模态引入人工阻尼**。

**校验（先验证再下结论）**：该格式给出的可用增益上限与**相位裕度定律**预测吻合：

| L | 相位裕度定律预测 | 积分实测 | 偏差 |
|---|---|---|---|
| 1 | 1570.8 | 1582.8 | +0.8% |
| 2 | 785.3 | 856.6 | +9.1% |
| 3 | 523.5 | 591.8 | +13.1% |

实测系统性**略高于**预测，因为判据是有限时域（0.5 s 内峰值有界），
比无穷时域的稳定性边界更宽松。**量级与 `1/L` 趋势一致**，故此格式可用于下述比较。

### 8.1 摩擦只在"远小于控制权限"时才不改变结论

参考幅值 1、`kp=100` ⇒ 比例控制权限约 `kp·A = 100`。以 `L=1` 为例：

| 粘性 c | 库仑 f_c | `f_c`/控制权限 | 上限 | 相对无摩擦 |
|---|---|---|---|---|
| 0.0 | 0.0 | 0 | 1582.8 | — |
| 0.5 | 0.2 | 0.002 | 1583.6 | **+0.05%** |
| 0.5 | 2.0 | 0.02 | 1589.5 | **+0.42%** |
| 0.5 | 20.0 | 0.2 | 1755.7 | **+10.9%** |
| 0.5 | ≥200 | ≥2.0 | 无上限 | — |

**正确表述**：摩擦**远小于控制权限**（`f_c ≲ 2%·kp·A`）时，上限变化 <0.5%，
成本是**延迟驱动**的；一旦摩擦**与控制权限可比**（`f_c ≈ 20%·kp·A`），
上限已被抬高 10.9%，**模型开始起作用**；摩擦再大则上限消失。

原版"差异 <0.1%"之所以成立，是因为当时 `f_c = 0.2` 而控制力约 `kd·v ≈ 10⁴`——
摩擦小 5 个数量级，**该比较本身是空洞的**。

### 8.2 ~~"每周期把可用增益除以 (L+1)"~~（**已撤销**）

原版比值 `1 : 0.502 : 0.311 : 0.225` 是 `Δt·kd = 2` 伪影的产物，**已撤销**。

修正后的真实上限（同 §8.0 表）确实**随深度下降**，但**不是 `1/(L+1)`**：
`L=1,2,3` 的比值为 `1582.8 : 856.6 : 591.8 = 1 : 0.541 : 0.374`，
而 `1/(L+1)` 给出 `1 : 0.5 : 0.333`——**形状相近但明显不同**，
且 `L=0` 在该被控例上**根本没有上限**。

**工程含义（保留但改口径）**：级联深度 `D` 且单趟执行 ⇒ 可用微分增益随深度显著下降；
两趟执行（`L=0`）把这份权限**全部保留**。
深度与可用带宽的定量关系见 §6.3 的带宽上限公式与
`hierarchical_control/test/test_scheduling_performance.cpp`。

### 8.3 执行器饱和会**掩盖**失稳，而不是消除它（**结论保留，数据重测**）

`kp=100`、`L=2`（`τ=2 ms`）、在 `t=1 s` 注入 `+0.05` 速度扰动：

| kd | 线性预测相位裕度 | 线性（无饱和） | 饱和 `u_max=200` | 饱和后跟踪误差 RMS |
|---|---|---|---|---|
| 300 | +51.5° | 有界（峰值 0.098） | 有界（峰值 0.098） | 0.715 |
| 600 | +21.2° | 有界（峰值 0.051） | 有界（峰值 0.051） | 0.713 |
| 1000 | **−24.6°** | **发散** | **有界（峰值 0.031）** | **0.711** |
| 2000 | **−139.2°** | **发散** | **有界（峰值 0.016）** | **0.709** |

**饱和把发散变成有界响应**：`kd=1000` 时线性回路发散，饱和回路峰值仅 0.031。
但饱和后的**跟踪误差 RMS = 0.711**，而 ±1 参考自身的 RMS 是 `1/√2 = 0.707`
——也就是说**输出与指令基本无关**，回路并未在控制。

> **"它不炸了"不等于"它能工作"。** 这是单趟 + 深级联在实际机器人上最危险的失效形态：
> 故障被饱和掩盖，只表现为精度差、抖动或执行器持续饱和。
> 注意 `kd=300`（裕度 +51.5°）的健康回路 RMS 为 0.715——**在该被控对象上 RMS 本身
> 无法区分好坏**，因此判据必须是**相位裕度 + 幅值**，这也再次印证 §6.1 的指标教训。

### 8.4 本节结论

- 深度代价是**结构性的**：在"摩擦远小于控制权限"的区间内，摩擦与量化不改变它；
- 但**该区间有边界**（约 `f_c ≲ 2%·kp·A`），越界后模型开始起作用——**不要声称无边界的稳健性**；
- 量化在极粗分辨率（`q=0.1`，即参考幅值的 10%）下仍不改变上限；
- 饱和只改变**表现**（发散 → 有界），不恢复控制能力；
- 因此：**在饱和系统上做实验必须同时报告相位裕度与跟踪误差**，否则会误判为稳定。
