## 0. 结论摘要（先给坏消息）

**目标（一个性能侧正结果）没有达成。** 但本报告给出了比"没做成"更有用的东西：

1. 「调度滞后 L」与「控制代价」之间缺失的那一环**已经补上并且可复现**：
   滞后 → 相位裕度损失 → 可用增益上限 → 闭环带宽；
2. 在该链条上，**两趟执行（L=0）保留平坦回路的全部控制权限，
   而单趟执行的可用增益上限按约 `1/(L+1)` 随深度下降**——这是可复现的定量结果；
3. **但本项目此前用于证明该代价的数值证据是伪影**：
   `CONTROL_COST_OF_LAG.md` §8.2 的增益预算比值 `1 : 0.502 : 0.311 : 0.225`
   精确等于 `1 : 1/2 : 1/3 : 1/4`，即**显式 Euler 积分的稳定性上限 `Δt·kd = 2`**，
   不是控制回路的可用增益上限；
4. 用**精确离散化**（`x''=u` 在控制量分段常值下的精确更新）测量，真实上限是另一条定律：
   `kp=100`、`Δt=1 ms` 下 `L=1,2,3` 的上限为 **1570.8 / 785.3 / 523.5**（比值 2.000 / 3.001），
   而 `L=0` **没有上限**。

**性能侧仍然没有正结果**，原因是结构性的（见第 5 节）。这与 `HANDOFF_MANUAL.md` §6 P1 的
预判一致，但现在能**精确定位**此前为什么会得到看似正面的增益预算结果。

## 1. 为什么实验必须建在 1 kHz 标量控制侧（纸面预算）

按 P1 要求先算预算，再决定值不值得跑。相位裕度损失 `ΔPM = 360·f_c·L·Δt`：

| 控制周期 Δt | 穿越频率 f_c | 每周期损失 | L=0 | L=1 | L=2 | L=3 |
|---|---|---|---|---|---|---|
| 1 ms（1 kHz） | 95.5 Hz | 34.4° | 90.0° | 55.6° | **21.2°** | **−13.1°** |
| 10 ms（100 Hz，管理器 fixture 的 `PERIOD`） | 95.5 Hz | 343.8° | 90.0° | **−253.8°** | — | — |

两个直接结论：

1. 效应只在高带宽回路（`f_c` 接近 `1/Δt`）显著；
2. **管理器 fixture 的 `PERIOD = 10 ms` 不能用于此类实验**（每周期损失 344°）。
   这解释了为什么 `test_two_phase_execution.cpp` 只能报告周期数、无法报告控制性能。

## 2. 已确立的定量结果：滞后 → 可用增益上限

`hierarchical_control/test/test_scheduling_performance.cpp`
（闭环、确定性、无 ROS、无仿真服务器）：

被控例 `x'' = u`，`u = kp(r − x_delayed) − kd·v_delayed`，`kp = 100`，调度滞后 `L` 周期，
控制器 1 kHz。被控对象用**精确离散化**（控制量在步内常值：`x ← x + Δt·v + Δt²/2·u`，
`v ← v + Δt·u`），因此**不存在积分误差冒充控制极限**。

**相位裕度定律**：`PM = atan2(kd·ω_c, kp) − ω_c·L·Δt`，`ω_c⁴ = kd²ω_c² + kp²`。

| L | 预测上限 | 时间域 0.95×上限 | 时间域 1.05×上限 |
|---|---|---|---|
| 0 | 无上限（>20000） | 有界 | — |
| 1 | **1570.8** | 有界 | **发散** |
| 2 | **785.3** | 有界 | **发散** |
| 3 | **523.5** | 有界 | **发散** |

- 深度定律：`上限(L=1)/上限(L=2) = 2.000`，`上限(L=1)/上限(L=3) = 3.001`
  ⇒ 每加一层，可用控制权限按 `(L+1)/L` 缩水；
- 相位裕度定律**预测**失稳起点，时间域**确认**：`kd=600`、`τ = τ₀·0.9` 有界、`τ = τ₀·1.3` 发散，
  其中 `τ₀` 由 `PM=0` 解出；
- 代价由**绝对延迟** `L·Δt` 决定，不由周期数 `L` 单独决定：同样 1 个周期，
  100 Hz 的裕度损失是 1 kHz 的 **10.00 倍**（恰好 `10.0`）。

**即：调度契约确实转化为控制权限。** 这是正结果，但它说明的是
「**两趟执行下深度不惩罚控制权限**」，**不是**「两趟执行让控制性能更好」。

## 3. 决定性诊断：既有增益预算证据是积分伪影

### 3.1 现象

`CONTROL_COST_OF_LAG.md` §8.2 报告
`kd_max(0):(1):(2):(3) = 1 : 0.502 : 0.311 : 0.225`，并解释为"每周期约把可用增益除以 (L+1)"。

这组数字**精确复现**，且**精确等于 `1 : 1/2 : 1/3 : 1/4`**。

### 3.2 根因

`test_stale_state_cost.cpp` 的 `simulate_plant()` 用**显式 Euler**：

```cpp
const double next_velocity = velocity + dt * (command - plant.viscous * velocity - friction);
```

`command` 含 `−kd·history_velocity[index]`，于是

```text
v ← v + Δt·(−kd·v + …)  =  (1 − Δt·kd)·v + …
```

放大因子 `|1 − Δt·kd|` 在 `Δt·kd > 2` 时大于 1 ⇒ **积分格式自身发散**。
有效阻尼就是 `kd`，所以该阈值随深度按 `1/(L+1)` 缩放——**这就是那组比值的来源**，
与调度无关。

### 3.3 真实上限是另一条定律

| | 显式 Euler "上限" | 精确离散化的真实上限 |
|---|---|---|
| 定律 | `Δt·kd = 2` ⇒ `1/(L+1)` | `PM = 0` ⇒ 由上表给出 |
| L=0 | ~2000 | **无上限**（`kd=20000` 仍有界） |
| L=1 | ~1000 | **1570.8** |
| L=2 | ~667 | **785.3** |
| L=3 | ~500 | **523.5** |

两者数值接近（这是为什么此前没被发现），但**属于完全不同的量**。

### 3.4 控制论解释（为什么真实上限是这个形状）

`L(s) = (kp + kd·s)/s²` 的穿越相位为 `−180° + atan2(kd·ω_c, kp)`。
延迟损失 `ω_c·L·Δt` 随 `kd` 增长而增长，而 `atan2` 项同时趋近 +90°；
两者在某个 `kd` 交叉 ⇒ **存在有限上限**，且该上限由 `PM=0` 精确给出。
注意这**不是** `1/(L+1)` 形式（真实比值在 L=1,2,3 上为 2.000 与 3.001，
但 L=0 是无上限，故整体不是 `(L+1)` 律）。

本轮另外用**插桩实测**澄清了 Humble 的排序机制（详见 `BIDIRECTIONAL_EDGE_ANALYSIS.md` §9）：
Humble 的 `controller_sorting` 比较器在**参考边**处**提前返回**，
其末尾的状态接口子句（带 `TODO(saikishor): deal with the state interface chaining`）
在双向对上**不可达**。因此 Humble 的"确定 reference-first"**不是取舍**，
而是**状态边从未参与排序**。

## 4. 对课题的真正含义

### 4.1 主命题不受影响

定理 1–3、单趟不可满足性、两趟充分性**不依赖**任何增益预算量。
契约层面的差异是**直接测出来的**：

- 内核级穷举 6 种顺序（`test_execution_group.cpp`）；
- 真实 `ControllerManager` 0/1/2 周期（`test_two_phase_execution.cpp`）；
- 真实 Gazebo 闭环 0 vs 1 周期（`GAZEBO_CASE_STUDY.md`）。

### 4.2 代价章节需改口径

| 内容 | 状态 |
|---|---|
| §2–§7 相位裕度定律与带宽上限 | **正确**，保留；本报告已独立复现（含绝对延迟 10 倍关系） |
| §8.1 摩擦/量化不改变代价（<0.1%） | **存疑**：建立在同一显式 Euler 的 `kd_max` 上，需用精确离散化重跑 |
| §8.2 `1 : 0.502 : 0.311 : 0.225` | **是伪影**，改为"真实上限 1570.8/785.3/523.5，比值 2.000/3.001，L=0 无上限" |
| §8.3 执行器饱和把发散变成极限环 | **存疑**：其"线性发散"前提来自同一伪影，需重跑 |

### 4.3 性能侧现状（诚实版）

- **CPU 时间**：负结果（约为手写 composite 的 2 倍），不变；
- **跟踪误差**：无正结果，且原因是结构性的：
  1. 低带宽回路本来不敏感（Gazebo `f_c ≈ 0.5 Hz`，一个周期仅 ~3.6°）；
  2. 高带宽回路上，滞后确实**限制可用增益**（第 2 节），
     但"用跟踪误差展示收益"需要回路工作在带宽受限区间，
     而这种回路**用小信号跟踪误差测量反而不敏感**——这是本轮的实测结论；
- **契约层**：成立且可复现（0 vs 1 周期），但这不是性能收益。

**论文口径**：
> 本文贡献是**不可能性 + 充分性修复 + 契约在真实系统中成立 + 代价定律的量化**；
> **不包含性能收益**。我们同时报告了一个此前被误读为收益证据的数值伪影及其修正。
